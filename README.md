# slog

极简学习记录 CLI：一天一个 Markdown 文件，五个板块，用编辑器书写。单文件 Python 脚本，零依赖。

数据永远是明文 Markdown，不进数据库，卸载工具不影响任何日志。

## 安装

要求：Python 3.6+，任一终端编辑器（默认 nvim）。

```zsh
git clone https://github.com/setsuna-1106/slog.git ~/Desktop/slog
ln -s ~/Desktop/slog/slog.py ~/.local/bin/slog
```

克隆路径可自定，软链接指向新路径即可（`~/.local/bin` 需在 PATH 中）。

## 使用

```console
$ slog
↩ 从 2026-08-24 带入：1 条未懂、1 条卡点、1 件待办
（编辑器打开今天，写完保存退出）
✓ 2026-08-25 已保存（学2 懂1 疑1 错1 待1）
```

日常只需这一条命令。其他命令：

| 命令 | 作用 |
|---|---|
| `slog` | 打开今天的日志（不存在则按模板新建，并带入上一篇的未完成内容） |
| `slog show [日期]` | 终端查看，日期支持 `yesterday`、`-3`（3 天前）、`2026-08-25`，默认今天 |
| `slog edit [日期]` | 编辑/补记某天，文件不存在会自动新建 |
| `slog recent [N]` | 最近 N 天一览（默认 7） |
| `slog search 关键词` | 全文搜索所有日志（不区分大小写） |
| `slog review` | 汇总最近一篇的还没懂/卡点，标注首次出现日期 |
| `slog stats` | 总天数、当前/最长连续天数、科目分布 |
| `slog path` | 显示日志目录 |

## 待办衔接

新建某天的日志时，自动向前找最近一篇（隔了几天也能接上），把未完成内容带入对应板块：

- `[?] 还没懂` 的非空条目
- `[!] 错误 / 卡点` 的非空条目
- `明天第一件事` 中未勾选的 `- [ ]` 条目（已勾 `[x]` 的跳过）

已经解决的，在编辑器里删掉那一行即可；完成了待办就补上 `[x]`。

## 备份

在日志目录 `git init` 后，slog 会在每次编辑保存后自动提交一个本地快照（纯本地，不联网）：

```zsh
cd ~/Desktop/University/Learning\ log
git init && git add -A && git commit -m "初始快照"
```

日志目录不是 git 仓库时，此功能自动不生效。

## 数据格式

```
Learning log/
├── template.md        # 模板（修改它会改变以后每天的初始格式）
├── 2026-08-25.md      # 一天一个文件
└── ...
```

```markdown
# Learning Log — 2026-08-25

## 学了什么
- 光学 光学历史介绍

## 弄懂了什么
- 光学 无阻力系统波的微分方程

## [?] 还没懂
- 光学 半波损失什么时候加

## [!] 错误 / 卡点
-

## 明天第一件事
- [ ] 光学 看第三章
```

统计中的「科目」取自条目第一个词（如 `光学 光学历史介绍` → 光学）。

## 配置

| 环境变量 | 说明 | 默认 |
|---|---|---|
| `SLOG_DIR` | 日志目录 | `~/Desktop/University/Learning log` |
| `EDITOR` | 编辑器 | `nvim`（如 `code -w` 用 VS Code 打开） |

## 卸载

删除 `~/.local/bin/slog` 软链接和 slog 目录即可，日志文件（含日志目录里的 git 快照）不受任何影响。
