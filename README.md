## ✨ 特性

| | |
|---|---|
| 📝 **纯文本数据** | 一天一个 `YYYY-MM-DD.md`，数据永远是明文 Markdown，不锁进任何数据库 |
| ⚡ **一条命令** | 敲 `slog` → 编辑器打开今天 → 写完保存退出，日常只需这一步 |
| 🔁 **待办衔接** | 上一篇的「还没懂 / 错误卡点 / 未勾选待办」自动带入新的一天 |
| 📊 **轻量统计** | 连续天数、科目分布，条形图直接画在终端里 |
| 🪶 **零依赖** | 单文件 Python 脚本，仅用标准库，克隆即用，卸载即走 |

## 🚀 快速开始

要求：Python 3.6+、任一终端编辑器（默认 `nvim`）。

```zsh
# 克隆到任意目录（下例为 ~/Desktop/slog，换路径只需同步改别名）
git clone https://github.com/setsuna-1106/slog.git ~/Desktop/slog

# 添加别名
echo 'alias slog="python3 ~/Desktop/slog/slog.py"' >> ~/.zshrc
source ~/.zshrc

slog   # 开始今天的记录
```

## 📖 使用

### 日常记录

```console

（编辑器打开今天，写完保存退出）
✓ 2026-08-25 已保存（学2 懂1 疑1 错1 待1）
```

### 命令一览

| 命令 | 作用 |
|---|---|
| `slog` | 打开**今天**的日志（不存在则按模板新建，并带入上一篇的未完成内容） |
| `slog show [日期]` | 终端查看，日期支持 `yesterday`、`-3`（3 天前）、`2026-08-25`，默认今天 |
| `slog edit [日期]` | 编辑/补记某天，文件不存在会自动新建 |
| `slog recent [N]` | 最近 N 天一览（默认 7） |
| `slog search 关键词` | 全文搜索所有日志（不区分大小写） |
| `slog stats` | 总天数、当前/最长连续天数、科目分布 |
| `slog path` | 显示日志目录 |

## 🔁 待办衔接

新建某天的日志时，自动向前找**最近一篇**（隔了几天也能接上），把未完成内容带入对应板块：

- `[?] 还没懂` 的非空条目
- `[!] 错误 / 卡点` 的非空条目
- `明天第一件事` 中未勾选的 `- [ ]` 条目（已勾 `[x]` 的自动跳过）

已经解决的，在编辑器里删掉那一行即可；完成了待办就补上 `[x]`。

## 📁 数据格式

```
Learning log/
├── template.md        # 模板（修改它会改变以后每天的初始格式）
├── 2026-08-25.md      # 一天一个文件
└── ...
```

每篇日志固定五个板块，统计中的「科目」取自条目第一个词（如 `光学 光学历史介绍` → 光学）：

```markdown
# Learning Log — 2026-08-25

## 学了什么
- 光学 光学历史介绍

## 弄懂了什么
- 光学 无阻力系统波的微分方程

## [?] 还没懂
- 光学 半波损失什么时候加

## [!] 错误 / 卡点
-

## 明天第一件事
- [ ] 光学 看第三章
```

## ⚙️ 配置

| 环境变量 | 说明 | 默认 |
|---|---|---|
| `SLOG_DIR` | 日志目录 | `~/Desktop/University/Learning log` |
| `EDITOR` | 编辑器 | `nvim`（如 `code -w` 用 VS Code 打开） |

## 🗑 卸载

删除 `~/.zshrc` 中的 alias 行和 slog 目录即可，日志文件不受任何影响。
