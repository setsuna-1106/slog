# slog — 极简学习记录 CLI

一天一个 Markdown 文件，五个板块，用你喜欢的编辑器书写。
零依赖（macOS 自带 python3 即可），数据永远是纯文本，属于你自己。

## 安装

```zsh
# 在 ~/.zshrc 中加入（已自动配置）：
alias slog="python3 ~/Desktop/slog/slog.py"
```

重新开一个终端，或执行 `source ~/.zshrc` 即可使用。

## 使用

| 命令 | 作用 |
|---|---|
| `slog` | 打开**今天**的日志（不存在则按模板新建，并带入上一篇的未完成内容） |
| `slog show` | 终端查看今天；`slog show yesterday`、`slog show -3`、`slog show 2026-08-25` |
| `slog edit -2` | 编辑/补记某天（文件不存在会自动新建） |
| `slog recent 14` | 最近 14 天一览（默认 7 天） |
| `slog search 光学` | 全文搜索所有日志 |
| `slog stats` | 总天数、当前/最长连续天数、科目分布 |
| `slog path` | 显示日志目录 |

日常只需记住一条：**敲 `slog`，写，保存退出**。

## 待办衔接

新建某天的日志时，自动向前找最近一篇，把三类未完成内容带入新文件对应板块：

- `[?] 还没懂` 的非空条目
- `[!] 错误 / 卡点` 的非空条目
- `明天第一件事` 中未勾选的 `- [ ]` 条目

已经解决的，在编辑器里删掉那一行即可；完成了待办就补上 `[x]`。

## 数据格式

与 `~/Desktop/University/Learning log/` 现有体系完全一致：

```
Learning log/
├── template.md        # 模板（修改它会改变以后每天的初始格式）
├── 2026-08-25.md      # 一天一个文件
└── ...
```

五个板块：`学了什么` / `弄懂了什么` / `[?] 还没懂` / `[!] 错误 / 卡点` / `明天第一件事`。
统计中的「科目」取自条目第一个词（如 `光学 光学历史介绍` → 光学）。

## 配置

| 环境变量 | 说明 | 默认 |
|---|---|---|
| `SLOG_DIR` | 日志目录 | `~/Desktop/University/Learning log` |
| `EDITOR` | 编辑器 | `nvim`（可改为 `code -w` 用 VS Code 打开） |

## 卸载

删除 `~/.zshrc` 中的 alias 行和 `~/Desktop/slog/` 目录即可，日志文件不受任何影响。
